# Copilot Prompt for CI Checks

## Example Prompts
- Run full ci checks
- Run and fix full ci checks

## Usage
- Use these prompts to trigger the CI check script (tools/check_ci.sh) directly from Copilot Chat.
- For "Run and fix full ci checks", Copilot will attempt to fix issues if possible, or provide guidance if not.

## Description
This prompt enables you to run the full CI checks or attempt to fix issues automatically using Copilot's capabilities.
