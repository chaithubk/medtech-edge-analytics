# Sepsis Model Artifact Guide

This directory contains the deployable TensorFlow Lite model used by the edge
inference service and Yocto images.

## Canonical Artifact

- `imx8-compatible-sepsis.tflite`

This is the only production model artifact path used in this repository.

## Lifecycle

- Model is generated by CI retraining workflow.
- If model bytes change, CI commits updated file to git.
- CI creates a model version tag for traceability.

## Consumption

- Local/service runtime: set `MODEL_PATH` to this file.
- Yocto: install this file in the image during recipe `do_install`.

See `docs/YOCTO_INTEGRATION.md` for recipe example and pinning guidance.

## Model Interface

- Input shape: `(1, 20)`
- Output shape: `(1, 1)`
- Output semantics: risk probability-like score in `[0, 1]`

## Clinical and Regulatory Note

This artifact is for engineering validation and edge analytics workflows. It is
not a certified medical device and must not be used as standalone clinical
decision authority.
